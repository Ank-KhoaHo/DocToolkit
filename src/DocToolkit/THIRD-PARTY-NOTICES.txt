Restoring without internet access
---------------------------------
Restore is the only step that needs a package feed. Nineteen packages in total (five direct,
fourteen transitive counting both System.IO.Packaging versions) have to be reachable from the
consumer's feed; after that DocToolkit itself makes no network calls at all. Every package above
is a plain managed assembly - none of them carry a native runtime payload or a post-restore
download step, so a mirrored feed is sufficient and nothing phones home at build or run time.

The full MIT licence text for DocToolkit itself is reproduced in the LICENSE file shipped
with this package. Each dependency above carries its own licence, reproduced by reference
via its NuGet package metadata (licence expression MIT or Apache-2.0).

DELIBERATELY EXCLUDED
---------------------
The following are commonly used for these tasks but are NOT free for commercial use and
must never be added: EPPlus >= 5 (Polyform Noncommercial), NPOI >= 2.8.0 (paid maintenance
fee for revenue-generating users), Spire.* (feature-capped free editions),
Syncfusion.* and QuestPDF (revenue-gated community licences), IronPDF (commercial).

ShapeCrawler was evaluated for PPTX support and removed before release: it pulled in
SkiaSharp and Magick.NET-Q16-AnyCPU, adding native .so/.dylib binaries and a large
runtimes/ payload that broke this package's pure-managed, no-native-binaries premise.
PPTX support is implemented directly on DocumentFormat.OpenXml instead.
